Settings

Playback

Region, audio format and quality

+

Applies to playback and downloads. Availability and actual bitrate depend on the track and your region. Changing quality reloads the current player.

Files & folders

Names, disc folders and ZIP layout

+

Choose a folder on your phone or SD card. Your choice is remembered.

The subfolder above is used for the default Downloads location. A custom location saves directly into the chosen folder.

Extensions are added automatically. Folder separators are not allowed in filename templates.

Available placeholders
{title}
Song title
{artist}
Track artist
{albumArtist}
Album artist
{album}
Album title
{year}
Release year
{track}
Track number, e.g. 03
{disc}
Disc number
{id}
Song ID
{language}
Song language

ZIP uses the folder choices above. For a single selected song, an M4A file is saved. Keep the app open until saving finishes.

Tag names

Explicit and original-date tags

+

Title, artist and album are always included when supplied by the service.

Lyrics

Embedded lyrics and separate files

+

Lyrics are saved only when available. These are plain text lyrics, not synchronised LRC.

Changes save automatically.
